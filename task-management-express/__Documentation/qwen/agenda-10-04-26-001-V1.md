## Technical Decisions

### 1. Aggregation Pipeline vs. find()
**Decision**: Use aggregation pipeline  
**Rationale**: 
- Single query for data + count (via $facet)
- Better performance with joins ($lookup)
- Consistent results (no race conditions)
- Aligns with existing pattern in user.service.ts

### 2. Cache TTL: 2 Minutes
**Decision**: 120 seconds  
**Rationale**:
- Balances freshness and performance
- Users may update date range frequently
- 80%+ cache hit rate expected
- Follows LIST category TTL from master system prompt

### 3. Default Date Range: 30 Days
**Decision**: If no range provided, use last 30 days  
**Rationale**:
- Prevents overwhelming queries
- Matches common user behavior (view recent history)
- Can be overridden with explicit dates

### 4. Status Filter: Completed Only
**Decision**: Only return completed tasks  
**Rationale**:
- Figma design shows "Task History" (implies completed)
- Different from general task list endpoint
- More focused use case
