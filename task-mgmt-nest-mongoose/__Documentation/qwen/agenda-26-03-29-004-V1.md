## 🎯 MIGRATION OBJECTIVE

Migrate the **Subscription Module** from Express.js to NestJS, enabling subscription plan management, user subscriptions, free trials, and hybrid Stripe/RevenueCat integration.

### **Business Value**
- **Subscription Plans**: Admin can create/manage subscription tiers
- **User Subscriptions**: Track user subscription lifecycle
- **Free Trials**: 7-day trial with card collection
- **Hybrid Gateway**: Stripe (web) + RevenueCat (mobile)
- **Auto-Renewal**: Automatic subscription renewals
- **RevenueCat Integration**: Mobile app subscriptions (iOS/Android)
